# brook

**Менеджер закачек для macOS с клавиатурным TUI.** Демон в фоне, терминальный клиент над ним — всё управление с клавиатуры.

---

## Зачем

Браузерные «download manager»-ы живут вне терминала и требуют мыши. `brook` — наоборот: управление клавиатурное, UI — в терминале, движок — отдельный процесс с gRPC API. Сегодня клиент один (ratatui), завтра по тому же API можно ходить чем угодно — хоть скриптом, хоть с другого хоста.

Только macOS (последняя релизная), только клавиатура, без плагинов и расширяемости. Торренты, мобильный клиент и замена `yt-dlp` — вне скоупа.

---

## TUI

Запуск — `brook` в любой директории. Если рядом нет работающего демона, клиент поднимет его сам и предложит остановить на выходе.

Окно — одна рамка с карточками. Сверху по центру — имя и адрес демона (`[ brook | 127.0.0.1:7090 ]`), снизу по центру — подсказка по клавишам. При сужении и потере коннекта адрес меняется на `reconnecting · #N` или `offline · <причина>`.

Карточка — три строки: имя файла, прогресс-бар, строка состояния (`⏸ paused · X GB of Y GB`, `✓ done · host · —`, `✕ failed · причина`). Выбранная карточка отмечена `▌` слева; при длинном списке справа появляется скроллбар. При `NO_COLOR` цвета отключаются, состояние читается по глифам.

Сортировка: сначала активные (`RUNNING → RETRYING → QUEUED`), потом приостановленные (`PAUSED`), затем завершённые (`DONE → FAILED`). Отменённые скрыты из списка до тех пор, пока не удалишь запись окончательно.

### Клавиши

| | |
|---|---|
| `↑` `↓` / `k` `j` | движение курсора |
| `Space` | главное действие над строкой под курсором — pause, resume или retry в зависимости от состояния |
| `Enter` | развернуть карточку (URL, путь на диске, детали ошибки) |
| `a` | добавить загрузку |
| `d` | удалить (с подтверждением) |
| `q` | выйти |

Подсказка в нижней рамке всегда показывает, что именно делает `Space` для текущей строки.

### Модалки

- **Add** — два поля: URL и папка. URL автоматически префилится из буфера обмена, папка — из дефолта сервера. `Tab` переключает поле, `Enter` отправляет, `Esc` закрывает.
- **Дубликат URL** — если такой URL уже в очереди, предлагает открыть существующую запись (`o`), добавить всё равно (`a`) или отменить (`Esc`).
- **Имя файла занято** — если файл с таким именем уже лежит в папке, открывается rename-модалка с префилом `<имя> (1).<ext>`. Можно поправить руками и подтвердить.
- **Quit** — три варианта: остановить демон и выйти (`s` — только если демон поднимали сами), выйти не трогая демон (`Enter` / `k`), отмена (`Esc`).

После успешного Add с авто-переименованием появляется toast `saved as <финальное имя>` на месте нижней подсказки.

### Remote

```sh
brook --remote HOST:PORT [--pass …]
```

TUI подключается к удалённому демону вместо локального. Если сервер поднят с паролем и `--pass` не передан — пароль спросят на TTY. Чужой демон на выходе никогда не гасится.

## Что умеет движок

- HTTP и HTTPS, пауза и возобновление по Range-запросам. После рестарта процесса всё, что поддерживает Range, продолжается с того же места.
- Параллельная загрузка: несколько соединений на файл, если сервер отдаёт Range. Иначе — один стрим, без resume.
- Поддержка ссылок без `Content-Length` (GitHub codeload и прочие CDN): один воркер, прогресс-бар в режиме «идёт работа».
- Автоматические ретраи с экспоненциальным бэкоффом и лимитом попыток.
- Постоянный бюджет памяти независимо от размера файла.

Cancel убирает недокачанные данные с диска, но оставляет запись в списке (чтобы было видно историю). Delete — убирает и запись тоже.

## Демон

```sh
brook server [--directory DIR] [--host H] [--port P] [--client-pass …]
```

- **`--directory`** опционален. Если задан — это корень песочницы: любая загрузка с путём вне этой папки отвергается. Если опущен и host остаётся loopback — sandbox отключён, разрешён любой абсолютный путь. Для биндинга на не-loopback флаг обязателен.
- **Биндинг на не-loopback** дополнительно требует `--client-pass` (bearer-аутентификация). Пароль можно передать через переменную окружения `BROOK_CLIENT_PASS`, чтобы не светить в истории шелла.
- **Дефолт для модалки Add в TUI** приходит от демона: сначала явное `download.default_dir` из `brook.yaml`, иначе корень `--directory` (если задан), иначе системная папка загрузок пользователя.
- **Один демон на пользователя** — параллельный запуск второго инстанса в том же окружении блокируется.

Конфиг и очередь хранятся в пользовательских каталогах платформы. Логи — JSON через `tracing`, в файл и в stderr; у каждого запуска и каждой загрузки свой корреляционный ID, чтобы было проще разобраться, что пошло не так.

## Разработка

Все проверки и запуски — через [justfile](justfile). Агент и человек не должны звать голый `cargo` для fmt/clippy/test: в justfile правильные флаги и nightly-rustfmt.

```sh
just                    # список рецептов
just build              # сборка workspace
just run                # brook (TUI) с произвольными аргументами
just run-server         # brook server (флаги — позиционными аргументами)
just test               # все тесты
just check              # fmt-check + clippy + test (гейт перед коммитом)
just fix                # clippy --fix + fmt
```

Архитектура и состав крейтов описаны в `CLAUDE.md`; код — источник правды.

Конвенции: коммиты и PR — English, Conventional Commits. Merge — squash only. Перед пушем — `just check`.
