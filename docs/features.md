# Функции MVP

Минимум, чтобы продукт стал полезен. Всё, что после MVP, — см. [post-mvp.md](post-mvp.md). Что никогда не делаем — раздел «Вне скоупа» внизу.

## Загрузки
- Добавление по URL (модалка по `a`, префилл из буфера обмена, если там URL).
- HTTP(S).
- **Пауза / возобновление** через Range-запросы; ресюм после перезапуска процесса.
- **Сегментированная загрузка**: N соединений на файл, если сервер поддерживает Range; иначе fallback на одно соединение.
- **Чанковая запись на диск** — буфер фиксированного размера (ориентир 64–256 KB на сегмент), без подгрузки всего файла в память. RAM-бюджет процесса постоянен и не растёт от размера файла.
- Дефолты и потолки (число сегментов на файл, число одновременных активных задач, дефолтная папка `~/Downloads`) читаются из TOML-конфига.
- Прогресс: процент, скорость, ETA, «скачано / всего».
- Отмена с удалением частичного файла (с подтверждением).
- Ретраи с экспоненциальным бэкофом и лимитом попыток.

## API (gRPC)
- **Единственный путь** между UI и движком — gRPC. Схема в `brook-proto`. См. [api.md](api.md).
- Сервер слушает только `127.0.0.1` (loopback). Публикация наружу — см. [post-mvp.md](post-mvp.md).
- Контракт: unary команды (`Add`, `Pause`, `Resume`, `Cancel`, `List`, bulk `PauseAll`/`ResumeAll`) + server-streaming событий (progress, state changes).
- Settings через API в MVP не входят — см. раздел «Конфигурация» ниже.

## Конфигурация (TOML)
- В MVP — `./brook.toml` из текущей рабочей директории («из-под ног»).
- Параметры: дефолты загрузок (сегменты, параллельность, папка), порт API, пути логов, поведение при дубликатах.
- Если файла нет — `brook` создаёт с дефолтами при старте и пишет путь в stderr.
- Неизвестные ключи → warning в лог; недопустимые значения → ошибка старта с явным сообщением.
- Правка — вручную; hot-reload не поддерживается.

## UI — `brook` (ratatui)
- Клавиатурное управление в терминале.
- Шорткаты: `a` add, `p` pause, `r` resume, `c` cancel, `o` open, `/` filter, `q` quit, `?` help.
- Навигация: `↑` / `↓` и `j` / `k`.
- **Разворот деталей** по `Enter` — под строкой расширенная карточка (полный URL, путь, сегменты, последние события).
- **Multi-select** клавиатурой: `Space` — toggle, `Shift` + стрелки — диапазон. Команды `p`/`r`/`c` применяются ко всем выделенным.
- Фильтр списка по `/` — по имени файла / URL.

## Обработка дубликатов — `ask`
- URL уже в очереди → модалка: `Open existing` / `Add anyway` / `Cancel`.
- Файл уже есть на диске → модалка: `Rename (auto)` / `Overwrite` / `Cancel`.

## Наблюдаемость
- **Структурированные логи JSON** через `tracing`.
- CorrelationId: `session_id` (на запуск процесса), `download_id` (на каждую загрузку). Оба поля — в каждом событии.
- Файл `~/Library/Logs/brook/brook-<session_id>.jsonl` + stderr.

## Вне скоупа
- Торрент / magnet — отдельный большой движок.
- Мобильный клиент.
- Облачная синхронизация очереди между устройствами.
