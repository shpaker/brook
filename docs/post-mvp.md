# Post-MVP

Всё, что идёт после MVP. К открытым вопросам по этому разделу возвращаемся после реализации MVP.

## Порядок

1. **`brook-app` (egui)** — зафиксировано первым.
2. **Лимит скорости** (глобальный и per-download).
3. **`brookd` + auth + TLS** — выделенный демон и защищённый публичный бинд, открывают remote-сценарий.
4. Всё остальное ниже — без зафиксированного порядка, обсуждаем ближе к делу.

## Клиенты и процессы

### `brook-app` (egui)
Нативное macOS-окно, стилизованное под TUI. Ключевые фичи:
- Трей-иконка, меню (Show / Pause all / Resume all / Preferences / Quit).
- Глобальный шорткат toggle окна (кандидат `Opt+Cmd+D`, настраиваемый в preferences).
- Темы: system / light / dark (дефолт — system).
- Клик по строке разворачивает детали; ПКМ — контекстное меню; двойной клик — open.
- Multi-select мышью (Shift-click, Cmd-click).
- Автостарт при логине (настраиваемо, по умолчанию вкл).
- Системные уведомления (завершение, ошибка).
- Пауза активных задач при system sleep, возобновление при wake.

Крейты: `eframe` / `egui`, `tray-icon`, `global-hotkey`. Стилизация под TUI — через дизайн-токены в отдельном модуле.

### `brookd` — выделенный демон
Отдельный бинарь с `brook-core` + `brook-api` без UI. Для headless-сценариев и удалённого доступа.
- `brook --connect <addr>` и `brook-app --connect <addr>` подключаются к локальному или удалённому `brookd`.
- До появления `brookd`: и `brook`, и `brook-app` — всё-в-одном (сервер крутится внутри их процесса).

## API

### Auth + TLS → public bind
Публичный бинд (`0.0.0.0`) запрещён, пока не внедрены auth и TLS.
- Варианты auth: API-key в gRPC-метадате / mTLS / basic.
- TLS: self-signed из коробки или пользовательский сертификат (обсудить).

### Settings через API
Методы `GetSettings` / `UpdateSettings`. Приходят, когда UI дорастёт до интерактивного редактирования настроек. Одновременно — **hot-reload TOML** (изменения применяются без перезапуска).

## Конфигурация

### Стандартный путь
`~/Library/Application Support/brook/config.toml` через `directories`. В MVP — CWD («из-под ног»).

## Функциональные фичи

### Скорость и расписание
- Лимит скорости: глобальный и per-download.
- Расписание (bandwidth window).
- Приоритеты в очереди.

### Захват URL
- Clipboard monitor.
- Browser integration (расширение).
- Drag & drop URL и файлов-списков.
- Batch import (range-паттерны `file[1-100].jpg`).

### Протоколы и источники
- FTP / SFTP.
- Multi-source / зеркала.
- yt-dlp как плагин.

### Надёжность и безопасность
- Проверка контрольной суммы (MD5 / SHA256).
- Auth для самих загрузок: basic / digest, заголовки, cookies.
- Прокси (HTTP / SOCKS5).

### Организация
- Категории / автомаршрутизация по типу файла.
- История с поиском.
- Шаблоны переименования.
- Определение дубликатов с хэш-сверкой.

### Интеграции
- Post-actions (открыть папку, уведомление, выполнить скрипт).
- CLI-клиент к API (аналог `transmission-remote`).

### Платформа
- Windows и Linux — кросс-платформенность после MVP.
