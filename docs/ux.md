# UX

`brook` — ratatui-клиент в терминале. Лёгкий список, развёртка по клавише, клавиатурный multi-select. Всё, что про нативное окно (трей, глобальный шорткат, клик мышью, темы, автостарт), — см. [post-mvp.md](post-mvp.md).

## Запуск
Сначала пользователь стартует демон `brookd` из CWD (он берёт lock на `.brook.lock`, открывает `./brook.db`, слушает gRPC на `127.0.0.1:7090`). Затем в том же или другом терминале — `brook` (TUI-клиент):
- Подключается к демону по gRPC (`--port`, дефолт 7090).
- Рендерит ratatui-UI, питается `Watch`-стримом.
- Если демон недоступен — сообщение в UI и exit.

Выход — `q`. Клиент закрывается, **демон и активные загрузки продолжают работать**. Остановить движок — `SIGTERM` / `SIGINT` на `brookd`.

## Клавиатура
Шорткаты (основной набор, из эскиза):
- `a` — add download (модалка URL; префилл из буфера обмена, если там URL).
- `p` — pause выделенного / всех выделенных.
- `r` — resume выделенного / всех выделенных.
- `c` — cancel выделенного (с подтверждением).
- `o` — open file (если done) или open folder.
- `/` — фокус на фильтр.
- `Esc` — close modal / close filter.
- `q` — quit (полный выход процесса).
- `?` — help overlay (краткий cheatsheet на одном экране).

Навигация и взаимодействие со списком:
- `↑` / `↓` **и** `j` / `k` — оба работают.
- `g` / `G` — в начало / в конец списка.
- `Enter` — развернуть / свернуть детали (см. ниже). Одновременно развёрнута **одна** строка.

## Multi-select (клавиатурой)
- `Space` — toggle выделения текущей строки.
- `Shift` + `↑` / `↓` (или `Shift` + `K` / `J`) — расширение диапазона.
- Команды `p` / `r` / `c` применяются ко всем выделенным. Для `c` — одна сводная модалка подтверждения.

## Мышь
Не обрабатываем. `crossterm` поддерживает мышь, но ориентация продукта — клавиатурная.

## Разворот деталей
`Enter` на выделенной строке раскрывает под ней карточку:
- Полный URL и целевой путь.
- Воркеры (прогресс каждого).
- Последние события — короткий хвост лога (state changes, ретраи, ошибки).
- Заголовки запроса (если кастомные).

## Дубликаты — `ask`
Модалка в ratatui:
- **Тот же URL уже в очереди** → `Open existing` / `Add anyway` / `Cancel`.
- **Файл существует на диске** → `Rename (auto)` / `Overwrite` / `Cancel`.

## Визуал
Ориентир — эскиз из первого сообщения. В ratatui воспроизводится прямо:
- Моноширинный шрифт — терминал и так моноширинный.
- Палитра ANSI-accent-цветов: фиолетовый — активное, розовый / красный — ошибка, зелёный — done, жёлтый — retrying.
- Блочный прогресс-бар (`ratatui::widgets::Gauge` или кастомный).
- Хинт-бар снизу с шорткатами.
- Индикаторы состояния слева от имени файла: `▶` / `❚❚` / `✓` / `✕`.

Заголовок окна из эскиза («pinned Opt+Cmd+D», «80×24») в ratatui неактуален. В TUI — короткий статус-бар вверху (активные / очередь / скорость).

## Полировка

- **`NO_COLOR`** — если переменная окружения выставлена, рендерим без ANSI-цветов: полагаемся только на символы-индикаторы (`▶` / `❚❚` / `✓` / `✕`).
- **Минимальный размер окна** — 60 × 15. Меньше — заглушка «brook needs at least 60×15», без попыток рендера основного интерфейса.
- **Форматирование байт** — humansize-стиль: `1.5 MB`, `532 KB`, `15 B`. Скорость — `1.2 MB/s`, `340 KB/s`.
- **Форматирование ETA** — короткое: `2h 15m`, `15m 30s`, `45s`, `<1s`.
- **Сортировка списка** — по состоянию: `RUNNING` → `RETRYING` → `QUEUED` → `PAUSED` → `DONE` → `FAILED` → `CANCELLED`. Внутри каждой группы — по `updated_at` убывающе.
