# UX

`brook` — ratatui-клиент в терминале. Лёгкий список, всегда видимая панель деталей снизу, клавиатурный multi-select. Всё, что про нативное окно (трей, глобальный шорткат, клик мышью, темы, автостарт), — см. [post-mvp.md](post-mvp.md).

## Запуск
Сначала пользователь стартует демон `brookd` из CWD (он берёт lock на `.brook.lock`, открывает `./brook.db`, слушает gRPC на `127.0.0.1:7090`). Затем в том же или другом терминале — `brook` (TUI-клиент):

- Подключается к демону по gRPC (`--port`, дефолт 7090).
- Рендерит ratatui-UI, питается `Watch`-стримом.
- Если демон недоступен — сообщение в UI и exit 1.

Выход — `q`. Клиент закрывается, **демон и активные загрузки продолжают работать**. Остановить движок — `SIGTERM` / `SIGINT` на `brookd`.

## Раскладка окна

TUI-приложение занимает весь терминал через `crossterm::EnterAlternateScreen`, на `Event::Resize` перерисовывается. Фиксированная вертикальная раскладка:

```
┌── status (2 строки) ───────────────────────────────────────────┐
│ brook  ●  127.0.0.1:7090                                       │
│ active 2/3 · queued 1 · paused 1 · retrying 1    ↓ 14.2 MB/s   │
├── list (Min(0), скроллируется) ────────────────────────────────┤
│    ▶  ubuntu-24.04.iso         782 MB / 1.8 GB  12.4 MB/s  2m ║│
│       ██████████████▓▓▒▒░░░▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░  42%  ║│
│                                                                │
│ ›  ▶  dataset.tar.gz           1.2 GB / 3.4 GB   1.8 MB/s 18m ║│
│       ██████████▓░░░░▒░░░░░░░▓░░░░░░░░░▒░░░░░░░░░░░░░░░  35%  ║│
│                                                                │
│ * ❚❚  pack.zip                 210 MB / 500 MB       —  paused ║│
│       ████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  42%   │
├── detail (Length(5)) ──────────────────────────────────────────┤
│  url     https://example.com/.../dataset-2026-q1.tar.gz        │
│  path    ~/Downloads/dataset.tar.gz                            │
│  pieces  45 / 128  ·  piece_size 32 MiB                        │
├── hint (1) ────────────────────────────────────────────────────┤
│ a add   p pause   r resume   c cancel   o open   ? help   q    │
└────────────────────────────────────────────────────────────────┘
```

- `status` — 2 строки, фиксировано сверху.
- `list` — гибкая, скроллируется; правый край — `ratatui::Scrollbar` при переполнении.
- `detail` — 5 строк, привязана к низу над hint-bar; автоскрывается при высоте терминала < 20, toggle `Tab`.
- `hint` — 1 строка снизу.
- **Минимальный размер** — 60 × 15; меньше — заглушка «brook needs at least 60×15».

## Статус-бар

Две строки.

**Строка 1** — идентичность процесса и состояние коннекта.

- `brook` — заголовок (прячется первым на узких терминалах).
- Индикатор коннекта: `●` зелёный (connected) / `◐` жёлтый (reconnecting, опционально `attempt N` после адреса) / `○` красный (disconnected).
- Адрес демона `127.0.0.1:<port>`. Порт всегда показываем.

**Строка 2** — runtime-счётчики и суммарная скорость.

- `active N/max` — всегда видно (даже при `N=0`), `max` = `download.max_concurrent`.
- `queued · paused · retrying` — видны только при значениях > 0.
- `cancelled` / `done` / `failed` — не показываются в статус-баре (видны в самом списке).
- Справа — `↓ <sum speed>` по всем `RUNNING`.
- При `disconnected` счётчики замораживаются, в конце строки приписывается `· stale`.

**Поведение при сужении** (по порядку дропа):
1. Заголовок `brook`.
2. `↓ <speed>` переезжает в хвост строки 2 после счётчиков.
3. Скорость совсем прячется.
4. Остаётся `● 127.0.0.1:<port>` и счётчики.

## Список загрузок

Каждая загрузка — **две строки**:

1. **Шапка**: префикс-маркеры (курсор `›` / selection `*` / иконка состояния) + имя файла + правая метрика-колонка (`bytes / total · speed · ETA/state`).
2. **Прогресс-бар** — во всю ширину списка под шапкой, выровнен с именем.

Между загрузками — пустая строка-разделитель.

**Иконки состояния:**

| иконка | state |
|---|---|
| `▶` | RUNNING |
| `❚❚` | PAUSED |
| `↻` | RETRYING |
| `⏳` | QUEUED |
| `✓` | DONE |
| `✕` | FAILED / CANCELLED |

**Правая колонка** — одной ширины по всему списку, поля правоприжаты:

- RUNNING: `782 MB / 1.8 GB · 12.4 MB/s · 2m 15s`
- PAUSED: `210 MB / 500 MB · — · paused`
- QUEUED: `— / 12 MB · — · queued`
- RETRYING: `420 MB / 900 MB · — · 3/10` (`attempt / max`)
- DONE: `48 KB / 48 KB · — · done`
- FAILED: `— / 1.2 GB · — · failed`

### Главный прогресс-бар и воркеры

Бар — непрерывная байтовая шкала. Три зоны:

- **Done** — `█` accent-цвет.
- **Активные куски воркеров** — по одному контигуитетному сегменту на воркер, ширина сегмента = `piece_size / total_bytes × bar_width`. Цвет берётся из циклической палитры по `worker_id % N_colors` (4–6 цветов). Весь сегмент одноцветный — без внутрикусочного прогресса.
- **Pending** — `░`.

Work-stealing виден естественно: у одного воркера кусок почти целиком «съеден» done-зоной, у другого только начался; между активными кусками — pending-дырки.

**`NO_COLOR`:** все активные куски — `▓`, done — `█`, pending — `░`. Воркеры перестают быть различимы, но положение работы видно.

**No-Range fallback** (`pieces_total = 1`): бар деградирует до `done + one active segment`, pending-дырок нет.

**Сортировка списка:** `RUNNING → RETRYING → QUEUED → PAUSED → DONE → FAILED`. Внутри каждой группы — по `updated_at` убывающе. `CANCELLED` фильтруется из списка (в брукd остаётся, пока не `Remove`).

### Скроллбар

`ratatui::widgets::Scrollbar` по правому краю области списка, появляется только при переполнении. Шаг скролла — строка (не «элемент»). На узких терминалах колонка под скроллбар отъедается у правой метрика-колонки.

## Детальная панель снизу

Пять строк, фиксированной высоты, разделена от списка горизонтальной линией. Всегда показывает детали загрузки **под курсором** (не Enter-разворот). Обновляется в реальном времени.

```
 url     https://example.com/datasets/dataset-2026-q1.tar.gz
 path    ~/Downloads/dataset.tar.gz
 pieces  45 / 128  ·  piece_size 32 MiB
 error   source mutated (412)                     ← только для FAILED
```

- `url` — длинный обрезается `…` по середине.
- `path` — resolved `target_dir / filename`.
- `pieces` — `N / total · piece_size X MiB`. Для no-Range: `single-stream (no Range)`.
- `error` — появляется отдельной строкой только в состоянии FAILED.

**Авто-скрытие** при высоте терминала < 20. **Ручной toggle** — `Tab`.

## Клавиатура

Шорткаты:

- `a` — add download (модалка).
- `p` — pause выделенных (или под курсором, если ничего не выделено).
- `r` — resume аналогично.
- `c` — cancel с confirm-модалкой.
- `o` — open file (если done) или open folder.
- `?` — help overlay.
- `Tab` — toggle detail-панели.
- `Esc` — close modal / close help.
- `q` — quit (полный выход клиента).

Навигация и выделение:

- `↑` / `↓` и `j` / `k` — курсор.
- `g` / `G` — в начало / в конец.
- `Space` — toggle выделения текущей строки.
- `Shift` + `↑` / `↓` или `Shift` + `J` / `K` — расширение диапазона.

**Фильтра `/` в MVP нет.** Список короткий (лимит параллельности 3), сортировка по состоянию достаточна.

**Мышь игнорируется** (`crossterm` поддерживает, но ориентация продукта — клавиатурная).

## Модалки

Центрированный блок поверх UI с рамкой и `Clear`-фоном. `Esc` закрывает, мышь не обрабатывается, clipboard-paste через `Event::Paste`.

### Add (`a`)

Минимальная форма:

```
┌─ add download ─────────────────────────────┐
│  url     https://example.com/file.iso_     │
│  folder  ~/Downloads                       │
│         [ add ]   [ cancel ]               │
│  Tab · switch   Enter · add   Esc          │
└────────────────────────────────────────────┘
```

- `url` префилится из clipboard, если там `http(s)://`.
- `folder` префилится из `download.default_dir` (сервер отдаёт через `GetSettings`).
- `workers` и piece-override'ы в модалке не настраиваются — идут с дефолтами сервера. Пользователь, которому это нужно, правит `brook.yaml` или ходит через `grpcurl`.
- Валидация URL на клиенте: непустой, схема `http(s)`. Ошибка от сервера (`InvalidArgument`, `FileExists`) показывается под полем, модалка остаётся.

### Confirm cancel (`c`)

```
┌─ cancel download? ──────────────────────────┐
│  ubuntu-24.04.iso  (42% · 782 MB)           │
│  partial file will be removed.              │
│       [ cancel download ]   [ keep ]        │
│                  y / n                      │
└─────────────────────────────────────────────┘
```

При multi-select — `3 downloads will be cancelled.`, одна сводная модалка. Горячие `y` / `n`.

### URL-дубликат

```
┌─ duplicate url ─────────────────────────────┐
│  this url is already in the queue.          │
│  existing: ubuntu-24.04.iso (RUNNING)       │
│  [ open existing ]  [ add anyway ]  [ × ]   │
│        o · open     a · add     Esc         │
└─────────────────────────────────────────────┘
```

Проверка дубликата — **на клиенте**, по текущему `ViewModel` до отправки `Add`. `open existing` — курсор прыгает на существующую запись; `add anyway` — шлём `Add` как есть.

### Файл существует

```
┌─ file exists ───────────────────────────────┐
│  ~/Downloads/file.iso already exists.       │
│  [ rename ]  [ overwrite ]  [ cancel ]      │
│       r · rename   o · overwrite   Esc      │
└─────────────────────────────────────────────┘
```

Показывается, когда сервер вернул `FileExists` на `Add`. Клиент повторяет `Add` с `on_file_exists_override = RENAME | OVERWRITE` — сервер сам подбирает имя (`file (1).iso`) или перезаписывает.

## Help overlay (`?`)

Полноэкранный слой поверх UI. Закрывается **любой клавишей** (клавиша не выполняется как команда — чтобы случайный `c` не отменил загрузку). При высоте терминала < 25 — скроллируется `↑↓`, закрытие только `Esc`/`q`/`?`.

Группировка: `navigation`, `actions`, `view`, `misc`. Текст плоский, без таблиц-рамок. Под `NO_COLOR` — без цветов.

## Модели, состояния и реконнект

- **ViewModel** мутируется только UI-task'ом в ответ на `UiEvent` (keyboard, watch-stream, command-result). gRPC-клиент и `Watch`-стрим живут в отдельных tokio-задачах и шлют события в mpsc.
- **Watch-стрим** — прозрачный реконнект с backoff. При успешном реконнекте сервер шлёт initial `Snapshot` по каждой загрузке — `ViewModel` перезаливается полностью.
- **Unary-команды** — `tokio::spawn` на каждый клик; результат возвращается в UI-task как `UiEvent::CmdResult`, ошибка сервера показывается toast'ом внизу (на 3 секунды).

## Полировка

- **`NO_COLOR`** — если переменная окружения выставлена, рендерим без ANSI-цветов. Полагаемся на символы-индикаторы (`▶` / `❚❚` / `↻` / `⏳` / `✓` / `✕`) и глифы прогресс-бара (`█` / `▓` / `░`).
- **Минимальный размер окна** — 60 × 15. Меньше — заглушка без попыток рендера основного интерфейса.
- **Форматирование байт** — humansize-стиль: `1.5 MB`, `532 KB`, `15 B`. Скорость — `1.2 MB/s`, `340 KB/s`.
- **Форматирование ETA** — короткое: `2h 15m`, `15m 30s`, `45s`, `<1s`.
